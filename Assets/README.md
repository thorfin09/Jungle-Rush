# Jungle Rush - Modern Endless Runner Game (Unity 6)

This project contains the complete modular architecture for a Temple Run-inspired 3D endless runner.

## Folder Structure

* **Assets/Scripts/**: Core gameplay scripts, managers, systems, state machines, and services.
* **Assets/Prefabs/**: Instantiated assets (tracks, obstacles, power-ups, coins, UI screens).
* **Assets/ScriptableObjects/**: Configurable data (biomes, upgrading parameters, cosmetics).
* **Assets/Materials/**: Visual styles and shaders.
* **Assets/Animations/**: Animator controllers and transitions.
* **Assets/UI/**: Textures, sprites, fonts, and UI layouts.
* **Assets/Scenes/**: Main gameplay scenes.
* **Assets/Audio/**: Sound effects and music tracks.

## Package Dependencies

To run this project, make sure the following packages are installed via the Unity Package Manager (UPM):

1. **Universal RP (URP)** - For modern, mobile-optimized graphics pipelines.
2. **Input System** - Needed for gesture swiping and controls.
3. **TextMesh Pro** - For high-quality, scalable UI text.
4. **Cinemachine** - For follow cameras, camera shake, and dynamics.
5. **Addressables** - For asset management.
